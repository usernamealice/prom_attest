# Random Quote Generator
## Автор: Галушко Алиса

### Данный графический редактор был создан для рандомной генерации цитат. Программа создана на Python с использованием библиотеки tkinter для GUI.

**Основные функции:**

* генерация случайной цитаты из предопределённого списка;
* отображение цитаты с указанием текста, автора и темы;
* сохранение истории сгенерированных цитат;
* фильтрация истории по автору и теме;
* автоматическое сохранение истории в JSON‑файл;
* загрузка истории при запуске приложения.

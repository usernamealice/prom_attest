# Random Quote Generator
## Автор: Галушко Алиса

### Данный графический редактор был создан для рандомной генерации цитат. Программа создана на Python с использованием библиотеки tkinter для GUI.

**Основные функции:**

* генерация случайной цитаты из предопределённого списка;
* отображение цитаты с указанием текста, автора и темы;
* сохранение истории сгенерированных цитат;
* фильтрация истории по автору и теме;
* автоматическое сохранение истории в JSON‑файл;
* загрузка истории при запуске приложения.
  
## **Установка:**

Требования: установлен Python 3.6 или выше.

**Шаги установки:**

1. Клонируйте репозиторий:

git clone <https://github.com/usernamealice/prom_attest>

cd random-quote-generator

2. Убедитесь, что у вас установлен Python 3.6+

Никаких дополнительных зависимостей устанавливать не требуется — используются только стандартные библиотеки Python.

3. Запуск приложения

Запустите приложение командой:

python quote_generator.py
